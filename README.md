# 게임 일정

명조 · 스타레일 · 원신 · 젠레스 · 이환 · 엔드필드 · 리버스 · 퍼니싱 · 아주르 프로밀리아의 픽업 배너와 특별방송, 콜라보·행사를 한곳에 모읍니다.

- **홈** — https://noondal.github.io/game-schedule/
- **전체 일정** — https://noondal.github.io/game-schedule/schedule.html
- **캘린더 구독** — https://noondal.github.io/game-schedule/schedule.ics
- **이전 화면** — https://noondal.github.io/game-schedule/legacy/dashboard.html

> 공식 발표 전 항목은 추정이라 실제와 다를 수 있습니다.
> 참고용으로만 사용하시고, 정확한 일정은 각 게임 공식 공지를 확인해 주세요.

---

이 저장소는 **산출물만** 담고 있습니다. 6시간마다 자동으로 갱신됩니다.

| 파일 | 내용 |
|---|---|
| `schedule.ics` | 캘린더 구독용 |
| `events.json` | 수집된 일정 원본 |
| `status.json` | 마지막 확인 시각, 항목 수, 경고 |
| `index.html` | 홈 |
| `schedule.html` | 전체 일정 (주 단위) |
| `game.html` | 게임별 일정 (`?g=게임키`) |
| `app.js`, `app.css`, `fx.js` | 화면 공용 스크립트·스타일 |
| `legacy/` | 이전 화면 (대시보드) |
| `dashboard.html`, `v2/` | 예전 주소 — 새 화면으로 넘겨줍니다 |

수집기 코드는 비공개 저장소에 있습니다.
