# 게임 일정

명조 · 스타레일 · 이환 · 엔드필드의 픽업 배너와 특별방송을 한 캘린더로 모읍니다.

- **시작 페이지** — https://noondal.github.io/game-schedule/
- **캘린더 구독** — https://noondal.github.io/game-schedule/schedule.ics
- **대시보드** — https://noondal.github.io/game-schedule/dashboard.html

> 공식 발표 전 항목은 추정이라 실제와 다를 수 있습니다.
> 참고용으로만 사용하시고, 정확한 일정은 각 게임 공식 공지를 확인해 주세요.

---

이 저장소는 **산출물만** 담고 있습니다. 6시간마다 자동으로 갱신됩니다.

| 파일 | 내용 |
|---|---|
| `schedule.ics` | 캘린더 구독용 |
| `events.json` | 수집된 일정 원본 |
| `status.json` | 마지막 확인 시각, 항목 수, 경고 |
| `dashboard.html` | 대시보드 |
| `index.html` | 시작 페이지 |

수집기 코드는 비공개 저장소에 있습니다.
